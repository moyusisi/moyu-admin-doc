# 资源管理

::: tip
本系统以角色为基础可以对每个接口单独控制数据范围 ，同一个角色访问不同接口时也可有不同的的数据范围。
:::

## 角色管理
角色用于进行权限控制，以角色为核心的权限管理通过`用户-角色-权限`的链路控制权限，通过`角色+接口`共同控制[数据范围](/moyu-boot/auth-data-scope.html)。  
以角色为核心进行权限管理时，支持**一人多角**，用户可同时具有多个角色的权限，无法进行角色切换。

### 添加角色
在「角色管理」中进行添加角色。

* 唯一编码：唯一标识，默认生成的编码会以`R`开头。

### 配置角色用户
在「角色管理」中，点击某个角色的用户列表，可添加/移除用户。

### 配置角色权限
在「角色管理」中，点击某个角色的功能权限，可添加/移除功能权限，包括`菜单`和`按钮`。

![配置功能权限](/assets/img/role_perm.png)

### 配置数据范围
在「角色管理」中，点击某个角色的数据范围，可配置接口的数据范围。  

![角色配置数据范围](/assets/img/role_scope.png)

## 岗位管理
岗位类似于角色组的概念，通过关联多个角色进行权限管理，以岗位为核心的权限管理通过`用户-岗位-角色-权限`的链路控制权限。  
以岗位为核心进行权限管理时，支持**一人多岗、一岗多角**，用户可以进行**岗位切换**，岗位切换后对应的权限也会变化。

### 添加岗位
在「岗位管理」中进行添加角色。

* 唯一编码：唯一标识，默认生成的编码会以`G`开头。
* 直属组织：岗位所在的组织机构，数据范围中`本部门`就是指岗位的直属组织(与角色中不同，角色中是用户所在的部门)。

### 配置岗位用户
在「岗位管理」中，点击某个岗位的用户列表，可添加/移除用户。


### 配置岗位角色
在「岗位管理」中，点击某个岗位的岗位角色，可添加/移除角色。  
一个岗位可以配置多个角色，权限会自动合并。**菜单透视**功能即可查看岗位最终拥有的菜单权限。
