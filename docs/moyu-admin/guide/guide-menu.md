# 资源管理

::: tip
本系统的资源划分为`模块`、`菜单`、`接口`，结合动态路由对导航栏、侧边栏、按钮、数据等进行管理。  
配置完资源后到「角色管理」分配权限并重新登录即可生效。
:::

## 模块管理
侧边栏所有的菜单都属于某一个模块，不同模块可以有不同的侧边栏菜单，模块即对应顶部的导航栏。

### 添加模块
在「模块管理」中进行添加模块。

* 唯一编码：唯一标识，默认生成的编码会以`m_`开头。
* 模块主页：模块默认的主页地址。
* 布局组件：模块内所有页面的布局，目前支持`Layout`，可扩展不同的布局。

![模块管理](/assets/img/module.png)

## 菜单管理
在「菜单树」/「菜单管理」中管理菜单资源，所有的菜单都属于某一个模块，可在上方模块列表中切换模块。  
菜单资源有`目录`、`菜单`、`按钮`等不同的类型。  

![菜单管理](/assets/img/menu.png)

### 添加目录
目录仅用于组织菜单，本身不对应页面和权限。  
目录下可添加目录或菜单。

* 唯一编码：唯一标识，默认生成的编码会以`dir_`开头。
* 是否可见：目录隐藏后，目录下的所有菜单均不可见
* 路由地址：目录的重定向地址，如目录主页。
* 简洁模式：当目录下只有一个菜单时，不显示目录直接显示该菜单。

![添加目录](/assets/img/add_dir.png)

### 添加菜单
菜单对应页面，菜单下可添加按钮，不可再添加菜单。

* 唯一编码：唯一标识，默认生成的编码会以`menu_`开头。
* 是否可见：菜单隐藏后不会出现在侧边栏中，但仍可以通过地址访问。
* 路由地址：菜单对应页面的路由地址，即浏览器地址栏中的路径。
* 组件地址：菜单对应页面的前端组件地址，通常应为`src/views/`目录下的`vue`文件。
* 固定显示：在页签中固定显示不可关闭。
* 是否缓存：使用`KeepAlive`组件缓存。

![添加菜单](/assets/img/add_menu.png)

#### 内链/外链
`内链/外链`为链接类型的菜单，也会出现在侧边栏中，与普通菜单不同的是打开方式不同
* 内链：在系统内容区通过`iframe`的形式打开
* 外链：在浏览器通过新页面打开

* 唯一编码：唯一标识，默认生成的编码会以`link_`开头。
* 链接地址：点击后访问的页面链接。

![添加链接](/assets/img/add_link.png)

#### 页面缓存
菜单页面支持`keep-alive`缓存，当菜单配置为缓存时，在多标签页模式下，页面会被缓存。

* 页面在首次打开时，会执行`onMounted`，但被缓存时，当点击页签重新回到缓存页面时只会执行`onActivated`。
* 关闭标签页会移除对应页面缓存，再次进入重建缓存。
* 系统以页面路由`path`为页签标识，以页面的完整路径`fullPath`为缓存标识，`path`相同则共享一个页签，若`fullPath`不同则在同一页签中重建页面。


### 添加按钮
按钮对应页面内的一个操作，常用于权限控制。前端通过`hasPerm`函数控制按钮显示。

* 唯一编码：唯一标识，默认生成的编码会以`btn_`开头。
* 权限标识：用于权限控制的标识，对应接口的唯一标识。

![添加按钮](/assets/img/add_btn.png)

菜单决定了用户是否可访问某个页面，按钮则决定了用户是否可访问某个接口。

## 接口管理
接口对应的是后端接口，其权限标识用于绑定按钮，控制是否允许访问；其数据范围在角色授权时设置，控制接口返回的数据范围。

* 权限标识：接口的唯一标识，遵循`模块:资源:操作`统一的[命名格式](/moyu-boot/dev-standard.html#权限标识规范)。
* 接口地址：后端接口的地址，如`/api/sys/user/page`。
* 数据范围：标识此接口是否有数据范围控制，有数据范围的接口，在「角色管理」分配权限时可选择具体的数据范围。

![添加链接](/assets/img/add_api.png)
