# moyuAdmin

## 项目介绍

::: tip
**moyuAdmin**是一个前后端分离的系统，由前端项目[moyu-antdv-admin](/moyu-admin/index)和后端项目[moyu-boot](/moyu-boot/index)组成。
通常情况下使用**moyuAdmin前端**特指`moyu-antdv-admin`项目。
:::

`moyu-adntdv-admin`是**moyuAdmin**管理系统对应的 vue3 前端实现，基于`Vite8`，集成`Vue Router`、`Pinia`、`Ant-Design-Vue`、`vxeTable`等开发，支持灵活的**动态路由**及**菜单管理**，用于前后端分离的企业级后台管理系统的前端项目。
