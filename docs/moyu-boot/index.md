# moyu-boot

## 项目介绍

::: tip
**moyuAdmin**是一个前后端分离的系统，由前端项目[moyu-antdv-admin](/moyu-admin/index)和后端项目[moyu-boot](/moyu-boot/index)组成。
通常情况下使用**moyuBoot后端**特指`moyu-boot`项目。
:::

`moyu-boot` 是是**moyuAdmin**管理系统对应的 Java 后端实现，基于 `Spring Boot 2.7.x` + `SaToken`，集成 Redis / MyBatis-Flex，采用 RBAC 权限模型，兼顾灵活的**数据权限**控制，用于企业级前后端分离的后台管理系统。

## 核心能力

* RBAC 权限模型（用户/角色/菜单/按钮权限）
* 岗位权限控制，切换岗位可切换权限(适用于兼职岗位场景)
* 登录认证与会话管理
* 接口鉴权（权限点校验 + 前后端联动）
* 数据权限（精确控制接口数据范围，相同角色不同接口也可配置不同的数据范围）
* 代码生成（从表结构快速生成 CRUD 的前端+后端代码）
* 日志审计（访问日志、操作日志等）

## 技术栈
| 分类         | 技术选型          | 说明                    |
| ------------ | ----------------- | ----------------------- |
| 运行时       | JDK 8             |                         |
| 构建工具     | Maven             | 支持`mvnw`              |
| Web 框架     | Spring Boot 2.7.x | 版本以 `pom.xml` 为准   |
| 权限认证框架 | SaToken           | 版本以 `pom.xml` 为准   |
| 数据访问     | MyBatis-Flex      | 版本以 `pom.xml` 为准   |
| 数据库       | MySQL 5.7 ~ 8.x   | 支持国产数据库如GaussDB |
| 缓存         | Redis 7.x         |                         |

## 必需服务
* 数据库：mysql或其他数据库
* Redis缓存

## 功能模块

按照功能模块划分，基础功能如下：
* **组织架构**：用于对组织机构和人员的管理
  * `组织管理`
  * `用户管理`
* **权限管理**：用于对系统进行权限控制
  * `岗位权限`
  * `角色管理`
* **资源管理**：用于对目录、菜单、按钮、接口等资源的管理
  * `模块管理`
  * `菜单管理`
  * `接口管理`
* **系统运维**：系统提供的基本运维功能
  * `会话管理`
  * `配置管理`
  * `三方接口管理`
  * `日志审计`
