# 代码生成
本系统提供了代码生成的工具，在 Java 后端在开发新业务模块时生成代码，提高开发效率。

## 生成代码内容

生成的内容既包括后端代码，也包括前端代码。

### 后端代码

* Controller（API）
* Service / ServiceImpl
* Mapper / xml(较少使用)
* Entity / Param / VO


| 类型     | 生成代码     | 说明                                                                                     |
| -------- | ------------ | ---------------------------------------------------------------------------------------- |
| 控制器   | `Controller` | 控制器接口，通常包括`list、page、detail、add、edit、delete`等<br>接口URL和鉴权注解       |
| 业务接口 | `Service`    | 业务操作接口，通常包括`list、pageList、detail、`<br>`add、update、deleteByIds`等方法     |
| 业务实现 | `Impl`       | 业务操作实现类                                                                           |
| 数据访问 | `Mapper`     | 数据库操作接口，通常会继承`BaseMapper`，并带有`@Mapper`注解<br>用于让 `MyBatis` 自动识别 |
| 实体类   | `Entity`     | 数据表对应的实体                                                                         |
| 参数对象 | `Param`      | 查询参数、表单参数对应的请求对象，通常会带有用于参数校验的注解                           |
| 视图对象 | `VO`         | 返回给前端的对象，会带有Json序列化的注解                                                 |

| 生成代码 | 分类     | 说明             |
| -------- | -------- | ---------------- |
| `Entity` | 实体对象 | 数据表对应的实体 |
| `Entity` | 实体对象 | 数据表对应的实体 |

### 前端代码

* `api.js` : 接口定义
* `index.vue`: 列表页面
* `detail.vue`: 详情页面
* `form.vue`: 表单提交页面

## 生成前准备
在`系统工具->代码生成`菜单中，可以对生成的代码进行配置。

### 1. 确认数据表结构
表名、字段名、主键策略、逻辑删除字段  
通用字段建议统一：`id`、`create_time`、`update_time`、`create_by`、`update_by`

### 2. 确认生成信息
确认包名`com.moyu.boot`和模块名`system`，生成的代码将位于此路径下。

### 3. 确认字段配置
确认字段名称、查询条件、哪些在列表显示、哪些需要表单填写以及表单控件的类型等信息
